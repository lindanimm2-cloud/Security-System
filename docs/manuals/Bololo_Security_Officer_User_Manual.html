You are there

04

Map, evidence, reports

Map
Your pin + jobs

Use Open in Google Maps for turn-by-turn. Set it before you drive.

Evidence
Photo / video

Plates, damage, scene as SOP allows. GPS stamps the file.

Report
Facts only

Time on scene, what you found, who you spoke to, outcome.

Second problem
New field incident

Do not bury a new crime in chat on the old ticket.

05

Chat, calls, SOS

Chat
Short updates

“En route 3 min.” “On scene, resident home, false alarm.”

Calls
Desk / client / crew

Silent panic: follow SOP before calling the house.

SOS
Hold on Field Home

Alerts Control Room and supervisor. Then cover + radio.

SOS
Only when you need backup

If you fire it by mistake, say so on radio immediately. Do not ghost.
