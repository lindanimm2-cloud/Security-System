01

Who this login is for

The Owner account sees the whole company. Use it to set people up and to audit the shift — not to sit on every radio call.

You use Owner for

  • Creating dispatchers, officers, technicians and clients
  • Company settings, branches and passwords
  • Customers, plans, store and install jobs
  • A morning read of the Ops Board

Hand these to others

  • Live panic dispatch → Control Room manual
  • Driving to a job → Officer manual
  • Fitting cameras → Installation manual
  • Household panic button → Client manual
Rule 01
Least privilege

Give each person the smallest role that still lets them work.

Rule 02
One login each

Never share the Owner password. Deactivate leavers the same day.

Rule 03
Doors

Control Panel /login · Officer /officer/login · Technician /tech/login · Client /portal/login · Supervisor /supervisor/login.

Faults & escalation

Login
Cannot sign in

Organisation + email + caps lock. Reset from Teams if you still have an admin. Else 4DS.

Access
Wrong screens

Wrong role on the user record — fix in Teams & Users.

Client
Panic dead

Confirm CLIENT login + active plan + a dispatcher on the board.

Map
Grey tiles

Map pictures need internet. Pins still work on a local network.

SOS
Platform down

Fall back to radio / phone SOP. Tell 4DS. Do not invent a second unofficial client list in a notebook that nobody else can see.
